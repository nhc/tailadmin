## Chips

Chips are compact UI elements representing inputs, attributes, or actions. In Material 3, chips have a boxier shape with rounded corners, updated color mappings, and support for dynamic color. There are four main types:

Input Chips: Represent complex information (like people, places, or tags) in a compact form. They’re editable, can show errors, support multiple entries, and can be reordered or expanded.
Choice Chips: Allow selection of a single option from a set (like radio buttons). Only one can be selected at a time; typically displayed horizontally.
Filter Chips: Used for filtering content (like tags or categories). Multiple can be selected or deselected; good alternative to checkboxes.
Action Chips: Trigger actions related to primary content. They appear contextually and dynamically, often after main content.
Design Principles:

Compact: Save space, represent discrete info.
Relevant: Clearly relate to their context.
Focused: Make tasks/content easier to manage.
Anatomy:

Container (with optional stroke)
Optional thumbnail (avatar/icon)
Text (label, tag, or action)
Optional remove icon (for input chips)
Behavior:

Chips can be predictive, editable, movable, expandable, and support multiple states (selected, error, etc.).
Placement is flexible: inline, stacked, or horizontally scrollable.
